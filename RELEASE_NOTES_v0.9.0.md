# Discus Fish Control / Acará Controle 0.9.0

Development release for OceanTech NOUR aquarium lights.

## Highlights

- Add and edit up to ten daily light schedule points in a chronological timeline.
- See the white, blue, green, and red levels on each point card.
- Preview changes on the graph while editing and identify duplicate active times before saving.
- Choose English or Brazilian Portuguese; the selection is saved on the device.
- Keep schedule controls unavailable until the lamp data has loaded.

## Build and installation

No APK is attached. Open the project in Android Studio, use JDK 17 or later, install Android SDK Platform 36, then choose **Build > Build APK(s)**.

## Validation status

The Activity compiles against Android SDK 36. The schedule editor and language selector still need a physical-lamp and on-device UI pass. No changes have been pushed to GitHub.
